Drop photos here to fill the gallery on the homepage.

Name them 1, 2, 3, 4, 5, 6 with a .jpg, .webp or .png extension —
for example 1.jpg, 2.jpg, 3.jpg.

They appear on the site automatically; no code changes needed. Any slot
without a file is simply skipped, and if none exist the grid stays hidden.

Square-ish photos look best. Keep each one under about 400 KB so the page
stays quick on phones.
