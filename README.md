# Coolcare Details

Website for Coolcare Details — mobile detail service in Las Vegas.

- `index.html` / `style.css` — static site, no build step
- `images/` — drop the real logo here as `logo.png` (used as favicon; can also replace the CSS hero logo)

Host anywhere static (GitHub Pages, Netlify, Vercel) with coolcaredetails.com pointed at it.
